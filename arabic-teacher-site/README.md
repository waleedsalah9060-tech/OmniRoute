# موقع اللغة العربية — أ. وليد الصاوي

منصة تعليمية عربية (RTL) لمعلم اللغة العربية: النحو والصرف والبلاغة والأدب
للمراحل الابتدائية والإعدادية والثانوية.

المصدر: ملف «موقع اللغة العربية.txt» من Google Drive
(رابط تصميم Gemini: https://g.co/gemini/share/aa52dc6614b9)

## هيكل المشروع

```
arabic-teacher-site/
├── index.html          # الصفحة الرئيسية (الهوية، المسارات، المختبر، المنهجية، الموارد، التواصل)
├── styles.css          # نظام التصميم والطبوغرافيا العربية وضبط التشكيل
├── app.js              # محرك التصفية والبحث والإعراب التفاعلي والتدريب
├── data/
│   └── lessons.json    # قاعدة بيانات الدروس والشواهد والتدريبات (قابلة للتوسع)
└── README.md
```

## التشغيل

الموقع ثابت (Zero-bloat) — لا يحتاج بناء. شغّل خادمًا محليًا من داخل المجلد:

```bash
cd arabic-teacher-site
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

> ملاحظة: عند فتح `index.html` مباشرة دون خادم يعمل الموقع أيضًا
> بالبيانات الاحتياطية المدمجة في `app.js`، لكن يُفضّل الخادم المحلي
> لتحميل `data/lessons.json` كاملًا.

## إضافة درس جديد

أضف كائنًا جديدًا إلى `data/lessons.json` بنفس البنية:

```json
{
  "id": "unique-id",
  "stage": "primary | preparatory | secondary",
  "stageLabel": "المرحلة الابتدائية",
  "branch": "نحو",
  "title": "عنوان الدرس المشكول",
  "summary": "ملخص الدرس",
  "shahid": { "text": "النص المشكول", "source": "المصدر", "analysis": "التحليل" },
  "irabInteractive": [ { "word": "كلمة", "parse": "إعرابها" } ],
  "quiz": { "question": "سؤال", "options": ["أ", "ب", "ج"], "answerIndex": 0, "explanation": "شرح الإجابة" }
}
```

## التصميم

- الاتجاه: عربي متقن `RTL` مع ضبط `line-height: 2.1` للنصوص المشكولة
- الخطوط: `Amiri` للمتون والشواهد، `IBM Plex Sans Arabic` للواجهة
- الألوان: كحلي `#0B192C`، أزرق ملكي `#1E3E62`، ذهبي معدني `#C59B27`، كريمي `#FAF7F0`
- متجاوب (Mobile-First) مع دعم الطباعة وإمكانية الوصول
